FINORA - ENVIAR PARA O GITHUB

1) Crie um repositório VAZIO no GitHub, por exemplo:
   finora-mobile

2) Extraia este ZIP.

3) Abra o Terminal/PowerShell dentro da pasta extraída.

4) Execute, trocando SEU-USUARIO:

git init
git add .
git commit -m "Finora Mobile v0.1"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/finora-mobile.git
git push -u origin main

5) No GitHub:
   Repositório > Actions > Compilar Finora Android

O workflow também executa automaticamente após o push na branch main.

6) Ao terminar:
   Abra a execução > Artifacts > Finora-Android-v0.1

Dentro estarão:
- app-release.apk   -> instalar/testar no Android
- app-release.aab   -> formato para publicação na Google Play

ATUALIZAÇÕES FUTURAS:
git add .
git commit -m "Atualização Finora"
git push
